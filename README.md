# Databases

This repository contains assignments, projects, and exercises completed as part of my Database course within the Data & AI program.

The course focuses on the design, implementation, and management of relational databases using SQL Server. Topics covered include database modeling, normalization, primary and foreign keys, constraints, views, stored procedures, transactions, and data integrity. Practical work involves designing complete database solutions, creating ER diagrams, writing SQL queries, and working with real-world business scenarios.

The projects in this repository demonstrate how to build structured and scalable database systems while following best practices for data consistency and normalization.

## Technologies

- SQL Server
- T-SQL
- Docker
- SQL Server Management Tools
- Entity Relationship (ER) Modeling

## Learning Outcomes

- Design normalized relational databases
- Create and manage tables, views, and stored procedures
- Implement primary and foreign key relationships
- Write efficient SQL queries
- Maintain data integrity through constraints and transactions
- Connect databases to external applications using Python
